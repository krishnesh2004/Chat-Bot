# 🧠 Chat-Bot (RASA Based Travel Assistant)

A modular AI chatbot built using the RASA framework to assist users with travel-related queries like booking, weather updates, and itinerary planning. Designed with a privacy-first architecture and optimized for backend scalability.

## 🚀 Features

- ✈️ Travel Booking Flow – Handles flight, hotel, and transport queries.
- 🌦️ Weather Info – Fetches real-time weather updates.
- 🗺️ Itinerary Planning – Suggests optimized travel plans.
- 🔐 Privacy-First Design – No sensitive data stored or exposed.
- 🧩 Modular Actions – All logic lives in `actions/actions.py` for clarity and reuse.
